# Diseño

Las decisiones visuales observables pertenecen a la aplicación web y a las primitivas compartidas de `packages/ui`. Consulta [`apps/web/DESIGN.md`](apps/web/DESIGN.md) para su implementación, Atomic Design, tokens, layout, responsive y accesibilidad.

La API y los packages distintos de `ui` no tienen una capa visual. `packages/ui` contiene foundations, atoms y molecules; los organisms y templates se conservan en las features web y las pages en App Router. Todavía no existe una identidad de producto completa.
